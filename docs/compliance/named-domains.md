# Domains the tree names

The publication check (osscheck) allows only `example.*` names and the RFC 5737 address ranges. The tree names the
domains below on purpose; every other domain finding is a defect. Reviewed for v1-alpha: word findings 0, address
findings 0, domain findings only these. A new entry is a decision, recorded here with its reason.
`tests/compliance/oss-gate.py` (rule domains, every CI job) reads the first name of each row: a domain of the tree whose
last two labels are not listed fails, and so does a listed domain the tree no longer uses. The line numbers under
"Where" are for reference: the gate checks only the domain names of the first column, never the lines.
