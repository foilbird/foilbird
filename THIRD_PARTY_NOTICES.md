# Third-party notices

This repository is licensed under the Apache License 2.0 (`LICENSE`, `NOTICE`). It contains no vendored third-party
source code. Third-party software enters only through builds, and every image build writes its own notices:

| Where | What |
|---|---|
| `<output dir>/THIRD-PARTY-NOTICES.txt`, in the image `/usr/share/foilbird/THIRD-PARTY-NOTICES.txt` | every third-party component of that image: name, version, licence, where its licence text is in the image, where it came from |
| `<output dir>/foilbird-sbom.cdx.json`, in the image `/usr/share/foilbird/foilbird-sbom.cdx.json` | the same components as a CycloneDX 1.5 SBOM (package URLs, SHA-256 of third-party `.deb`s and release files) |

Both are generated by `images/debian/tools/image-sbom.py` at the end of `profiles/k8s-worker/mkosi.finalize` from the
image root (dpkg status, `/usr/share/doc/*/copyright`, `/usr/share/foilbird/sbom/*.json`, the agent's CycloneDX). The
build fails if a Debian package has neither a copyright file nor a recorded licence.

## What a k8s-worker image contains

| Component | Source | Licence |
|---|---|---|
| Debian 13 packages (kernel, systemd, libraries, tools) | Debian archive | per package, `/usr/share/doc/<package>/copyright` in the image |
| kubelet, kubeadm, cri-tools, kubernetes-cni | pkgs.k8s.io (signed APT repository) | Apache-2.0 |
| containerd, runc | GitHub releases (checksums; runc GPG-signed) | Apache-2.0 |
| nvidia-container-toolkit-base | nvidia.github.io/libnvidia-container (signed APT repository) | Apache-2.0 |
| NVIDIA open kernel modules | built from NVIDIA's `nvidia-kernel-open-dkms` source package | MIT OR GPL-2.0-only |
| NVIDIA user-space driver, GSP firmware | NVIDIA's Debian 13 repository | NVIDIA proprietary licence (`/usr/share/doc/<package>/copyright`) |
| node agent `foil-agent`, `foilctl` | this repository; Rust crates listed in `agent/Cargo.lock` | Apache-2.0; crates under their own licences (in the SBOM) |
| `foil-k8s-env` | this repository (Go standard library only) | Apache-2.0; Go: BSD-3-Clause |

Container images that the deployment manifests reference (for example `deploy/device-plugin/`) are not part of the node
image and carry their own notices.

## NVIDIA components are not redistributed

Images that contain NVIDIA components (the user-space driver, firmware and the kernel modules built from NVIDIA's
source, `.ko` files included) are built by each deployment from NVIDIA's repository under NVIDIA's licence terms. This
project publishes the sources and the build recipe only, never such images, packages or modules. In the notices and the
SBOM, these components are marked `NVIDIA component: … not redistributed` / `foilbird:redistribution=not-published`.
